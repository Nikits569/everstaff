# EVERstaff.agency
Corporate website for an international recruitment agency specializing in executive search and complex hiring.

## 🚀 Features
- Responsive design
- Django backend
- SEO optimized
- Control 90% information in admin panel 
- Contact forms
- Auto translate if admin put english version empty

## 🛠 Tech Stack

- Python
- Django
- HTML
- CSS
- JavaScript
- Bootstrap
- MySQL
